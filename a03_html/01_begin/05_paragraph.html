웹 프로그래밍이란?

웹 프로그래밍은 웹 사이트나 웹 어플리케이션을 개발 하는 것을 말한다 이것은 html, css, javascript 같은 프론트엔드 기술을 사용하여 사용자 인터페이스를 구축하고 백엔드 기술로는 서버 즉 언어나 데이터베이스를 다루는 기능을 포함한다 웹 프로그램밍은 웹사이트의 모습과 기능을 디자인하고 구현하는데 중첩을 두며 사용자가 쉽게 상호작용할 수 있도록 만드는 것이 목표이다
