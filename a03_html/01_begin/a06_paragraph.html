Oracle, HTML, CSS, JavaScript, Python 개요

Oracle: 오라클(Oracle)은 세계적인 IT 기업 오라클에서 제작한 관계형 데이터베이스 관리 시스템(RDBMS)입니다. 뛰어난 안정성과 트랜잭션 처리 능력, 대용량 데이터 처리 성능을 갖추고 있어 대기업 및 금융권의 핵심 데이터베이스 시스템으로 널리 사용됩니다.

HTML: HTML(HyperText Markup Language)은 웹 페이지의 구조와 뼈대를 정의하는 표준 마크업 언어입니다. 제목, 본문, 링크, 이미지 등 웹 문서의 각종 구성 요소를 태그 형태로 표현하며, 브라우저가 이를 해석하여 화면에 시각적으로 출력합니다.

CSS: CSS(Cascading Style Sheets)는 HTML로 작성된 웹 문서의 레이아웃, 색상, 폰트, 애니메이션 등 시각적 스타일을 디자인하는 스타일 시트 언어입니다. 웹 페이지의 구조(HTML)와 디자인(CSS)을 분리하여 유지보수를 용이하게 해줍니다.

JavaScript: 자바스크립트(JavaScript)는 웹 페이지에 동적인 기능과 상호작용을 추가하기 위해 사용되는 프로그래밍 언어입니다. 클라이언트 측 브라우저 실행 환경뿐만 아니라 Node.js를 통해 서버 측 백엔드 개발에도 널리 활용되고 있습니다.

Python: 파이썬(Python)은 문법이 간결하고 읽기 쉬워 생산성이 뛰어난 고성능 다목적 프로그래밍 언어입니다. 웹 개발(Django, Flask), 데이터 분석, 인공지능(AI), 머신러닝, 자동화 스크립트 작성 등 다양한 분야에서 강력한 라이브러리 생태계를 바탕으로 많이 사용됩니다.
