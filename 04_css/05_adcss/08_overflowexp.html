1. 선물상자 숨기기 (overflow: hidden)

선물상자가 너무 많아 크기를 초과했지만, 넘친 내용이 깔끔하게 잘려서 보이지 않습니다!

2. 고대문서 스크롤하기 (overflow: scroll)

고대문서의 방대한 기록입니다. 항상 스크롤바가 표시되어 언제든 전체 내용을 읽을 수 있습니다.

3. 선글라스 광고 박스 (overflow: visible)

광고 내용이 박스 밖으로 튀어나와 시선을 강탈하는 입체적인 효과를 줍니다!

4. 책 페이지 넘기기 (overflow: auto)

내용이 적을 때는 깔끔하게 유지되고, 지정된 크기를 넘칠 때만 자동으로 스크롤바가 생성됩니다.
